# 모바일 성능과 장르 기능 — 1.1.0

## 참고한 공개 게임 소개
- [신화 서바이버즈](https://play.google.com/store/apps/details?id=com.pixery.mythicsurvivors): 직업별 전투, 스킬 조합, 큰 보스와 강력한 필살기.
- [Survivor.io](https://play.google.com/store/apps/details?id=com.dxx.firenow&hl=en_US): 한 손 조작, 적 무리, 스킬 성장.
- [Vampire Survivors](https://poncle.games/vampire-survivors): 생존과 반복 플레이, 플레이 보상으로 영구 강화.

위 페이지는 기능 참고 자료이다. 타사의 비공개 소스, 리소스, 실제 기기 FPS나 구현을 확인하지 않았다. 모든 기능을 복제했다는 주장이나 타 게임과 같은 성능이라는 주장을 하지 않는다. 균열의 수호자는 자체 코드·픽셀 그래픽·합성 음향으로 구현한다.

## 이번 버전
- 초당 60회 고정 전투 계산: 30/60/120 Hz 화면에서 이동과 전투 시간이 같음. 150ms까지만 따라잡고 장시간 정지 후 급격한 이동은 방지.
- 탄환 충돌은 재사용하는 공간 격자에서 가까운 적만 검사. 빠른 적 탄환도 이동 경로 전체 검사. 밀려난 적의 격자 위치도 갱신.
- 배경 타일을 한 번 만들고 재사용. 화면 안의 적만 정렬하며 탄환과 효과도 화면 밖에서 그리지 않음.
- HUD 갱신은 10Hz. 장시간 24ms 초과 프레임이 발생하면 자동 모드에서 해상도를 단계적으로 줄이고 필요하면 화면을 30FPS 목표로 전환. 충분한 여유가 돌아오면 해상도 복구.
- 화면 성능 설정: 자동 / 부드럽게(60FPS 목표) / 배터리 절약(30FPS 목표, 해상도 축소). 전투 계산은 모든 모드에서 60Hz.
- 적 180, 플레이어 탄환 180, 적 탄환 160, 효과 160, 드롭 400, 보급품 12의 상한. 드롭을 합칠 때 경험치와 회복량 보존.
- 오디오 최대 24개 동시 음원, 종료한 노드는 연결 해제. 백그라운드에서는 오디오와 예약 효과 정지.
- 이동 조이스틱은 긴 드래그를 따라 이동하고 작은 흔들림을 무시. 두 번째 터치로 회피·궁극기를 즉시 실행.
- 스킬 다시 뽑기 도전당 3회, 모든 무기 6종의 별도 진화, 연결 패시브 Lv.2 조건을 선택 카드에 표시.
- 선택지에 성장 가능한 보유 무기를 하나 이상 제공. 정예가 떨어뜨리는 경험치·회복 상자, 90초마다 모든 경험치를 당기는 인력 상자.

## 측정 방법과 한계
`npm run benchmark`는 저장소의 자체 1.0.0 코드와 현재 코드를 같은 합성 충돌 장면으로 비교한다. 적 130마리와 탄환 2/18/64개, 동일한 무효 hit 함수로 충돌 비용을 분리한다. 300회 준비 후 2000회 측정을 3번 진행한다. 결과는 `release/performance.json`에 저장한다.

브라우저 스트레스 테스트는 모바일 화면의 Chromium과 WebKit에서 170마리와 진화 무기 장면의 업데이트·렌더링 비용을 기록한다. 보고서의 stress-frame-samples 첨부에서 확인한다. CI 실행 환경과 iPhone의 실제 칩·메모리·iOS·토스 WebView는 다르다. 이 수치로 실제 아이폰 FPS, 발열 또는 배터리 사용량을 보증하지 않는다.

## 실기기에서 마칠 일
콘솔 QR로 5분 전체 도전, 레벨업/진화/정예/보스/종료 후 저장을 확인한다. 자동과 배터리 절약 모드에서 각각 10분 이상 플레이하고 장시간 멈춤·발열·음향·Safe Area·두 손가락 조작을 확인한다. 실제 기기 모델과 iOS/토스 버전, 모드, 재현 장면을 함께 기록한다.
