# 다음 게임성 개선 — 4.0 이후 제안

4.0에서 공격을 직업별 8종·전체 24종으로 늘리고, 모든 공격에 Lv.3/5 자동 각성을 적용했습니다. 재질 이펙트 36프레임·새 스킬 그림 6개·녹음 효과음 29개를 반영했습니다. 현재 변화는 [전투 개편](COMBAT-4.0.md)에 정리합니다.

## 1. 공격의 진화 분기와 조합

3.1.1 점검에서 확인한 화면 크기별 난이도 편차를 먼저 조정한 뒤 진행할 게임성 개선입니다. 4.0의 자동 각성에서 추가 참격·흡인·도탄·왕복·잔류 지대가 적용됐습니다. 다음에는 같은 공격에서도 선택에 따라 다른 성장 경로가 생기도록 분기와 기술 간 조합을 확장합니다. 각 직업에서 최소 세 가지 구성이 성립하도록 설계합니다.

| 직업 | 구성 후보 | 구현 후보, 아직 미구현 |
| --- | --- | --- |
| 기사 | 회오리 근접 / 출혈 폭발 / 방어 강타 | 강타로 기절한 적에게 검기 적중 시 방어 파쇄, 회오리와 출혈 파열의 전용 조합 강화 |
| 궁수 | 관통 연사 / 독과 덫 / 광역 화살 비 | 화살 폭우가 독 지대를 남김, 덫에 묶인 적에게 관통 화살이 갈라짐 |
| 마법사 | 번개 연쇄 / 화염 폭발 / 빙결 제어 | 빙결 적에 번개 적중 시 얼음 파편, 운석으로 점화한 적에게 화염구 추가 폭발 |

현재 Lv.3/5 자동 각성 이후, 다발 / 집중 / 지속 같은 두 갈래 중 하나를 선택하는 방식도 검토합니다. 양쪽의 피해 기대값은 비슷하게 유지하고 장점과 단점을 함께 표시합니다. 진화 조건이 충족되어야만 조합이 발동하며 원형 공격을 식별할 수 있는 이미지와 소리가 필요합니다.

검증 기준: 같은 직업으로 세 판을 할 때 적어도 두 가지 다른 구성과 이동 방식이 성립해야 합니다. 하나의 구성만 무조건 유리하면 조합 계수나 적 구성을 다시 조정합니다.

## 2. 중간 보스와 적 역할

현재 일반 적 네 종류, 정예와 최종 보스만으로는 전투 흐름이 빨리 익숙해집니다. 약 90초와 180초에 서로 다른 중간 보스를 넣고, 방패 적·돌진 적·자폭 적처럼 대처법이 다른 적을 조합하는 편이 우선입니다. 체력을 일괄적으로 늘리기보다 위험 방향·피할 시간·공격 후 빈틈을 명확히 만듭니다.

검증 기준: 어떤 공격에 맞았는지 작은 휴대폰 화면에서 알아볼 수 있어야 합니다. 보스 준비 동작과 피격 위치가 일치하고, 화면 밖 즉사 공격이 없어야 합니다.

## 3. 한 판의 목표와 반복 보상

휴대폰에서 5–8분 정도의 도전, 다른 배치와 적 편성의 두 번째 전장, 직업별 달성 목표와 외형 보상이 필요합니다. 예: 궁수로 관통 처치 100회, 균열 세 번 봉인. 도전 종료 화면에 사용 스킬·피해 기여·다음 목표를 보여 줍니다.

현재 보석은 현금·토스 포인트·광고 보상이 아닌 기기 저장 게임 재화입니다. 포기와 사망도 현재 도전의 처치 수와 레벨로 정산하며 영구 강화에 사용합니다. 3.1.1에서 시작 직후 종료의 보석 반복 획득을 수정했습니다. 남은 보석 곡선과 영구 강화 비용은 반복 플레이 데이터를 모아 조정해야 합니다. 실제 결제나 광고를 붙이기 전에 반복 플레이 자체가 재미있는지 먼저 확인합니다.

## 4. 실제 iPhone에서 연출과 성능 평가

효과의 크기보다 공격 종류와 위험 방향을 읽기 쉬운 것이 먼저입니다. 발사 / 비행 / 명중 음량, 여러 스킬이 겹칠 때의 소리, 캐릭터와 적의 가림을 맞춥니다. 실제 iPhone 토스에서 스피커와 이어폰으로 청음하고 10분 이상 플레이하면서 입력 반응·끊김·발열을 확인합니다.

자동 Chromium/WebKit 검사와 CI 계산 성능은 실제 iPhone 토스의 FPS·청감·재미를 증명하지 않습니다. 콘솔 연결과 실제 기기 검증은 별도 단계입니다.

추천 순서: 화면 크기별 난이도 편차 → 진화 분기와 조합 → 중간 보스와 적 역할 → 전장과 반복 목표 → 실제 기기 반복 조정. 실제 기기 플레이 검토는 가능해지는 즉시 각 단계와 함께 진행합니다.
