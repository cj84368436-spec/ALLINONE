# Rift Keepers 2.0 — 개발·게임 디자인·아트 디렉션 작업 지침

사용자는 비개발자이며 아이디어와 플레이 소감으로 요구를 전달한다. 구현자는 다음 세 역할을 함께 수행한다.

- 게임 개발자: 모바일 조작, 프레임 비용, 실제 피격 판정과 이펙트·소리의 시점을 책임진다.
- 게임 디자이너: 회피, 목표 달성, 성장 선택 사이에 판단할 이유를 만든다.
- 아트 디렉터: 승인된 손그림 판타지 화풍을 유지하고 화면의 명암·색·크기·UI 위계를 통일한다.

## 메타프롬프트

“균열의 수호자를 아이폰에서 플레이하는 토스 2D 생존 액션으로 발전시켜라. 추상적인 품질 불만을 캐릭터 식별성, 전투 위험의 예고, 공격의 준비·발사·접촉, 의미 있는 성장 선택, 모바일 가독성이라는 검증 가능한 작업으로 바꾸어라. 기존 기록과 조작을 보존하라. 실제 게임 렌더러로 화면을 검토하고 정상 조작으로 완주 가능성을 확인하라. 정지 화면의 화려함을 전체 게임 완성도와 동일시하지 말라. 테스트 범위와 실제 기기 검증의 한계를 밝혀라.”

## 이번 구현

- 전장: 직접 생성한 회청색 유적 바닥 WebP. 큰 식생 소품은 전장 가장자리로 옮겨 전투 영역을 확보한다.
- UI: 남색 소재, 금빛 주요 행동, 원거리·마법 색상 구분. 홈의 영웅 전신을 가운데 배치하고 일관된 카드·버튼·글자 크기를 사용한다.
- 전투: 기사 광역 참격·기절, 궁수 9발 관통 일제사격, 마법사 4초 서리 지대. 실제 피해·투사체·둔화와 각 효과를 연결한다.
- 목표: 35/110/185/260초에 선택형 균열. 18초 안에 원 내부 누적 3초를 채우면 XP·회복·필살기 재충전. 원 밖에서는 진행이 조금씩 감소한다.
- 압박: 분마다 적의 추가 편대, 정예 적의 0.7초 방향 고정 예고 후 돌진. 선택과 일시정지 중에는 전투 시간이 멈춘다.
- 성장: 보유 무기와 필요한 진화 룬을 제안하고 다음 피해·범위·발사 수·진화 진행을 표시한다. 4개 무기 제한과 기존 진화 조건을 유지한다.
- 오디오: 기존 라이선스가 확인된 녹음 소스를 영웅별로 조합·재생한다. 효과음 전체를 새로 녹음했다는 뜻은 아니다.

## 품질 판정과 한계

Node 규칙 검사, Chromium/WebKit 모바일 설정 조작·UI 검사, 정상 조작만 사용하는 9개 시드 완주, 부하 검사, .ait 빌드를 실행한다.
.evidence/rift-2.0 이미지는 실제 Canvas/DOM 화면이다. 전투 장면은 검토에 필요한 적·시간·성장을 배치한 장면이며 실제 사용자 플레이의 재미를 증명하지 않는다.
아이폰 실물·토스 실기기 성능과 청감, 애니메이션의 상용 게임 수준 완성도, 토스 심사 승인은 이 자동 검사만으로 보장하지 않는다.
