# 스킬 연출 재설계 — 4.1.0

4.0에서 자동 검증을 통과했지만, 칼날 방벽의 무기 형태가 작고 흐렸고 칼날 회오리는 같은 이펙트 그림을 겹쳐 돌렸으며 영원의 서리는 비슷한 평면 기둥을 반복했습니다. 기능과 로딩 검사는 이 시각적 결함을 판단하지 못합니다. 사용자 프롬프트 부족이 아니라 제작 방식과 시각 검토 기준의 문제입니다.

## 이번 수정

- 칼날 방벽: 금속의 밝은 면·어두운 면·중앙 능선·날·가드·손잡이를 직접 그립니다. 실제 충돌 위치와 같은 궤도에서 이동하며 지나간 방향에만 짧은 잔상을 남깁니다. 뒤쪽과 앞쪽을 나눠 캐릭터가 궤도 안에 서 있는 깊이를 표현합니다. Lv.5 바깥 칼날은 반대 방향으로 회전합니다.
- 칼날 회오리: 반복 그림 대신 세 줄의 움직이는 나선 검격, 선명한 금속 검, 가늘고 밝은 선두와 짧아지는 꼬리를 조합합니다. 캐릭터를 덮는 전체 발광판을 제거하고 앞뒤 연출을 나눕니다.
- 영원의 서리: 준비 단계의 지면 균열, 크기·각도·분출 시점이 다른 9개 결정 군집, 여러 면의 얼음 굴절과 내부 균열, 충격 순간의 비산 파편을 그립니다. 큰 결정은 사라지고 바닥의 깨진 얼음과 저온 잔류 영역이 남습니다. 반복 구름 그림을 배치하던 지속 영역도 교체했습니다.
- 방벽·회오리 접촉은 넓고 흐린 공통 그림 대신 짧은 금속 교차 선과 불꽃으로 표현합니다.
- 연출 감소·낮은 해상도 모드에서는 파편과 세부 선을 줄이고 핵심 칼날과 결정 형태를 유지합니다.

이번 변경은 렌더링 개편입니다. 공격의 피해·쿨다운·성장·저장 모델은 유지합니다. 음원도 4.0의 실제 재질 녹음을 사용합니다.

## 제작 기준

| 순서 | 작업 | 판단 기준 |
| --- | --- | --- |
| 1 | 대표 스킬의 형태와 동작 설계 | 이름을 가려도 검·얼음·화염을 구분할 수 있는가 |
| 2 | 준비 → 발동 → 접촉 → 잔류 설계 | 실제 피해 순간과 시각적 충격이 맞는가 |
| 3 | 무기·결정 본체 제작 | 강한 발광을 빼도 재질과 윤곽이 보이는가 |
| 4 | 움직임과 깊이 | 같은 그림을 단순히 확대·회전한 인상에서 벗어나는가 |
| 5 | 잔상·빛·파편·소리 | 본체를 흐리지 않고 힘과 속도를 강화하는가 |
| 6 | 작은 전투 화면 검토 | 영웅·적·위험 예고를 함께 읽을 수 있는가 |
| 7 | 여러 기술이 겹치는 상태·실기기 검토 | 화면과 소리가 뭉개지지 않고 입력·발열이 허용되는가 |

최종 목표는 일관된 원화·애니메이션·재질·조명·명중 리듬입니다. 생성한 정지 이미지와 발광을 늘리는 것만으로 상용 액션 게임의 완성도를 얻을 수 없습니다. 원화와 VFX 애니메이션을 전문 제작 수준으로 다듬는 반복 작업이 필요합니다. 현재의 Canvas 2D로도 선명한 형태와 움직임을 구현할 수 있지만, 디아블로의 고밀도 3D 재질·조명과 같은 결과를 냈다고 평가하지 않습니다.

## 실제 검토

[모바일 전투 캡처](../../../.evidence/rift-4.1)에서 세 기술의 발동 시간대별 화면, 연출 감소 화면, 두 배 확대 상세 화면과 기존 24개 기술의 회귀 화면을 확인합니다.

캡처는 실제 게임 렌더러를 사용하지만 적과 시간을 배치한 시각 검토 장면입니다. 자동 픽셀 검사는 형태 소실·정지 그림·일시정지 오류를 찾는 도구이며 사람이 느끼는 미적 품질을 증명하지 않습니다. 실제 iPhone 토스의 청감·발열·장시간 성능 평가는 별도입니다.
