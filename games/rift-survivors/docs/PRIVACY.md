# 데이터 안내
균열의 수호자 1.4.0은 토스 익명 식별키로 해당 기기에 게임 기록을 저장합니다. 점수, 보유 보석, 강화, 누적 처치 수, 승리/도전 수와 설정이 토스 SDK Storage에 남습니다.

이름, 전화번호, 이메일, 위치, 주소록, 사진을 요청하지 않습니다. 게임 자체 서버, 외부 광고/분석 서비스로 사용자 정보를 전송하는 기능은 없습니다. 토스 SDK 자체 통신에는 토스 정책이 적용됩니다.

기기 변경이나 미니앱 데이터 삭제 시 기록이 이어지지 않을 수 있습니다. 별도 서버 동기화는 없습니다.

운영자는 콘솔에 실제 고객센터와 필요한 운영자 표시 정보를 등록해야 합니다. 운영자 정보가 확인되지 않아 본 문서를 최종 법정 개인정보처리방침으로 표시하지 않습니다.
